# Mobile Attendance Database

## Overview

This is an academic database project for a Mobile Attendance System designed to support employees who work outside the company, such as field and delivery workers.

Instead of requiring employees to return to the office to record their attendance, the system allows them to use a mobile application to check in and check out while working in the field.

This project focuses specifically on the database side of the system, including the design and implementation of the data required to manage employees, attendance records, breaks, and requests.

## Project Includes

- ER Diagram
- Relational Schema
- SQL DDL Scripts
- SQL DML Scripts
- JOIN Queries
